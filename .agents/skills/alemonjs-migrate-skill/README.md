# ALemonJS Migrate Skill

阿柠檬迁移Yunzai插件技能

## 安装

### VSCode Github

将此仓库克隆到项目的 `.github/skills/` 目录下：

```bash
git clone --depth=1 https://github.com/yunzaijs/alemonjs-migrate-skill .github/skills/alemonjs-migrate
```

或使用 Git Submodule 跟踪上游更新：

```bash
git submodule add https://github.com/yunzaijs/alemonjs-migrate-skill .github/skills/alemonjs-migrate
```

### Cursor

将此仓库克隆到项目的 `.cursor/skills/` 目录下：

```bash
git clone --depth=1 https://github.com/yunzaijs/alemonjs-migrate-skill .cursor/skills/alemonjs-migrate
```

或在 `.cursor/rules` 中引用 SKILL.md 内容。

### Windsurf

将此仓库克隆到项目根目录并在 `.windsurfrules` 中引用：

```bash
git clone --depth=1 https://github.com/yunzaijs/alemonjs-migrate-skill .windsurf/skills/alemonjs-migrate
```


## 插件克隆

应该在要开发的项目中克隆仓库到plugins目录来方便skill读取
